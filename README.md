## 1. What this project is

Kimiya is a small programming language in which chemical formulas and equations are part of the language. You can write `H2O` or `Ca(OH)2` directly in a program, and the
language checks every element against the periodic table. It can balance equations, check
equations that the user balanced by hand, and do the usual textbook calculations: molar mass,
grams to moles, how much product a reaction gives, how much of another reactant is needed, and
which reactant runs out first. Next to that it has the normal things a language needs: variables,
conditions, three kinds of loop, functions and lists.
